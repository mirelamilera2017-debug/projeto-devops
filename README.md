# Projeto DevOps

## Objetivo do projeto
Criar e executar uma aplicação web containerizada utilizando Docker e Docker Compose.

## Serviços utilizados
- Aplicação Web com Nginx
- MySQL
- phpMyAdmin

## Portas
- Aplicação: 8080
- phpMyAdmin: 8081

## Subir o ambiente
docker compose up -d --build

## Remover o ambiente
docker compose down
